Installing RedM

Start by installing Red Dead Redemption 2
Once you have Red Dead Redemption 2 installed, you can download RedM by doing the following:

  1. Visit the RedM website

    - https://redm.net/
  2. Select Download client RedM.exe
  3. Select Sure, I agree!
  4. Locate RedM.exe
    - Default location: C:\Users\[USERNAME]\Downloads\RedM.exe
  5. Run RedM.exe

    - If you run the installer in a folder with less than 3 files, RedM will install there. Otherwise, it will install in: C:\Users\[USERNAME]\Downloads
